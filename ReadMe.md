# 💫 About Me:
I am a Cloud and DevOps Engineer with over 6+ years of experience in architecting, deploying, and automating cloud infrastructure using Azure and AWS. My expertise spans across cloud computing strategy, infrastructure provisioning, and CI/CD pipeline automation using tools like Terraform, Ansible, Jenkins, and Docker. I specialize in designing cost-efficient, secure, and scalable solutions, with a strong focus on infrastructure as code (IaC) and cloud-native technologies.<br><br>I have hands-on experience with server management, O365 administration, and Active Directory, alongside a solid foundation in Linux and shell scripting. I am currently enhancing my skills in Python scripting for automation and diving deeper into Kubernetes, Terraform, and monitoring solutions like Prometheus and Grafana. As a continuous learner, I am passionate about multicloud architectures, and I’m actively expanding my knowledge in Azure DevOps, Kubernetes, and full-stack development.<br><br>Beyond the technical realm, I am a proactive problem solver and have supported clients in cloud migration, database performance tuning, and cybersecurity risk mitigation. I’m driven by innovation and love to share my knowledge through blogs and technical content on platforms like LinkedIn.<br><br>In my spare time, I enjoy reading books , practicing shell scripting, and contributing to open-source communities.
